Ensembled Model for Explainable Diabetic Retinopathy Detection Jan 2026 - May 2026

An advanced clinical-grade artificial intelligence framework designed for high-confidence Diabetic Retinopathy (DR) detection and grading, achieving an 93% base multi-class accuracy. By combining state-of-the-art dual-backbone representations with probabilistic evidence fusion, the system provides both highly accurate grading and self-aware epistemic uncertainty estimations to ensure patient safety.

Key Highlights:
  • 🧠 Dual-Backbone Feature Fusion: Combines a Convolutional Neural Network (ConvNeXt-Tiny) and a Vision Transformer (Swin-Tiny) to capture both micro-scale lesions (e.g., hemorrhages) and macro-scale structural anomalies in retinal scans.
  • 🛡️ Evidential Deep Learning (EDL): Implements Dempster-Shafer (DS) evidence combination on network heads, parameterizing Dirichlet distributions to model explicit epistemic uncertainty, warning clinicians of out-of-distribution/noisy images.
  • 📊 Clinical Referral System: Employs a reject-option model simulation where high-uncertainty scans (approx. 20-30%) are referred to human specialists, lowering Expected Calibration Error (ECE) and boosting accuracy on the remaining automated cohort.
  • 👁️ Ben Graham Contrast Filter: Performs specialized image preprocessing, including black boundary cropping and local contrast enhancement (Gaussian blur subtraction) to highlight subtle pathological details.
  • 🧠 Interactive Explainable Interface: Features a real-time Streamlit dashboard showing dynamic Grad-CAM heatmaps with interactive coordinate hover tooltips pointing out critical diagnostic zones.

People Counting & Tracking System

An end-to-end Deep Learning tracking system designed for crowd management, monitoring occupancy limits by automatically counting people entering or exiting a designated area based on a configured reference line.

Tracking Methodology:
  • Object Detection: Detects individuals within a video frame using YOLOv3 bounding box identification.
  • Centroid Tracking: Registers and computes the geometric centroid for each person, and assigns a constant unique Object ID.
  • Continuous Monitoring: Calculates Euclidean distance across successive frames to map similarity metrics, tracking individuals reliably.
  • In/Out Operations: Evaluates directional flow relative to the reference line, incrementing up/down counters in real-time.
